# ПаркМесто — бронирование парковочных мест

Учебный сайт: пользователь выбирает место на схеме парковки, указывает срок и госномер, видит стоимость и подтверждает бронь. Брони можно открыть в разделе «Мои брони» и отменить.

## Функции

Сценарий разбит на шаги: **Выбор места → Оформление → Готово**, плюс отдельный раздел **«Мои брони»**. 

- **Схема или список.** Переключатель «Схема | Список». Оба вида показывают одни и те же места с одинаковыми фильтрами.
- **Схема парковки:** разметка, проезд и въезд. Занятые места показаны машинами. Свободные — белые плашки с номером и ценой. Выбранное место синее, с галочкой. Бронь — синяя машина с подписью «Ваша».
- **Фильтры в одну строку:** выпадающий список «Цена» и чипы типа места. Повторное нажатие на выбранный тип снимает фильтр. 
- **Проверки:** нельзя продолжить без выбранного места, занятое место выбрать нельзя. Ошибку показывают пустое или нецелое количество, количество вне диапазона, пустой или неверный госномер. Повторное нажатие не создаёт вторую бронь.

## Ограничения

- Брони хранятся только в localStorage текущего браузера. В другом браузере или после очистки данных сайта их не будет.
- Бронь начинается с момента подтверждения (в оформлении видно «Начало: сейчас → Окончание»). Выбрать будущую дату или время нельзя. Место считается занятым, пока бронь не отменят. Календаря и проверки пересечения времени нет.
- Оплаты и реальной отправки данных нет.
